# SME Lending Decision and Portfolio Monitoring Platform

## Project objective

This project develops an end-to-end SME lending analytics platform covering
credit-risk assessment, credit decisioning, risk-based pricing, behavioural
monitoring and model governance.

The project uses an independently generated synthetic portfolio because
confidential real-bank customer data is not available.

## Business questions

1. What is the 12-month probability of default for each applicant?
2. Which applicants should be approved, referred or declined?
3. What lending rate is required to cover expected loss and meet the ROE hurdle?
4. Which booked borrowers are showing early signs of deterioration?
5. Which healthy borrowers are suitable for a proactive credit-line increase?

## Project milestones

1. Synthetic portfolio generation and data-quality audit
2. WoE-logistic credit scorecard development
3. Credit-policy decisioning and risk-based pricing
4. Early-warning monitoring and line-management strategy
5. Model validation, documentation and governance

## Important limitation

All customer records and outcomes are synthetic. The project demonstrates
analytical methodology and implementation, but the resulting models are not
suitable for real lending decisions without development on representative
historical data and independent validation.
